# Ana Jane Castillo — Personal Portfolio

A responsive personal portfolio for Ana Jane Castillo, graduating Bachelor of Science in Information Technology student at La Consolacion University Philippines.

## Sections

Home, About, Skills & Tools, Featured Project, Achievements, and Contact.

## Technology

HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser. No build process is required.

## Deploy to Vercel

Import the GitHub repository and use **Other** as the framework preset; leave the root directory at `./`.

## Notes

Replace `assets/documents/ana_cv.pdf` with Ana Jane's actual CV before publishing. The current attached PDF belongs to someone else.
